# 猎萨 · 木喉到海加尔

1.2.2 版：海加尔三处残骸、两位长老、三只幼兽、工坊与任务对话按实际目标指引。可在达埃古恩扫荡前顺路接地狱犬尖刺。峰顶哨兵、引兽、涤净力量及回报杰雷曼按前置交付顺序接续，背包路线允许跳过精英支线。

适用于 WoW Forever 部落猎人和萨满的简体中文 Polestar 路线包。两人从费伍德木喉任务起步，经冬泉谷进海加尔，在山上分别取得邮政背包和树皮背包（各 18 格）。可以和猎萨 50–60 完整路线同时启用。

## 安装与开始

1. 安装 Polestar 0.4.1 系列。
2. 在 WowUp 的「从 URL 安装」中输入本仓库地址并选择 Forever 客户端，或从[正式版下载页](https://github.com/ufolyx-niper/PolestarPack_HyjalDirect/releases/latest)下载名称以 `-forever.zip` 结尾的附件，将里面的 `PolestarPack_HyjalDirect` 文件夹解压到 `_forever_/Interface/AddOns/`。
3. 重启游戏，在 Polestar 列表选择「猎萨 · 木喉到海加尔」，或输入 `/polestar guide hyjal-direct/main`。猎人和萨满各自打开一次即可。

## 一条连续路线

费伍德南北死木村 → 木喉冷淡 → 穿隧道进冬泉谷准备隐遁药水 → 暗语峡谷 → 海加尔邮差、树皮地穴 → 山麓工坊、西北哨站、荒野诸神与永恒峰 → 树皮尊敬购包。

- 两人的木喉声望都到冷淡就过洞。准备打黑喉要塞时才顺路补中立，两个海加尔背包都不要求木喉中立。
- 55 级进山时先做树皮任务，达到 56 级后路线会回到邮差起点。山顶与永望镇之间送完回邮，每人领取一个 18 格邮政背包。
- 山上任务收尾后回地穴结算声望。死木洞救援和精英支线出现在顺路任务栏。尊敬后每人用 15 颗死木部族珠向达拉购买另一个 18 格背包。
- 西北哨站可接物资、引熊及部族战绘差事，达埃古恩可接剑圣突袭和法师塔信号，山麓工坊可擂鼓引奇美拉。回永恒峰交付时查看杰雷曼回报。山顶书架从 57 级提示。精英战斗和依赖它们的后续都能跳过。
- 老兵从千针石林或赤脊山送回的两种《赞许》通往同一位老兵。森金村的跨区投递和老兵远行在双包后按实际任务接续。
- 从 1.1.0 更新可继续用原主路线。已经走过的新增停靠可能显示为已过，可在步骤列表查阅。
- 1.0.0 已打开的章节标签会合并。路线保留兼容的旧手动勾选及已固定的查看位置，按角色的任务、航点、声望和物品继续判断下一步。

[路线与升级接续说明](PolestarPack_HyjalDirect/README.txt)。已通过本地 Polestar 引擎测试，尚未进行双角色实服全程通跑。
